# 2026-08-03

## 分析 Frappe Builder 项目（builder 仓库）
- 定位：frappe.io 的低代码网页建站工具，作为 Frappe App 安装（MIT）。
- 技术栈：后端 Python+Frappe15（BS4 渲染、RestrictedPython 沙箱、litellm/OpenRouter AI、DuckDB 分析、pandas/jsmin/csscompressor）；前端 Vue3+TS+Vite+frappe-ui（yarn workspace vendored）。
- 核心抽象：Block 模型前后端统一。前端 src/block.ts（Block 类 1097 行）是编辑器数据核心；后端存 JSON blocks。
- 渲染管线：JSON blocks → 展开组件 → 解析 props/dataKey(safer_exec) → BS4 建 DOM → 样式+media query → Jinja → SSR。草稿/发布双轨 + Builder Snapshot 回滚。
- AI：ai_page_generator 用 litellm，block↔YAML 压缩，Socket.io 流式回传。
- 风险点：巨型类（builder_page.py 1734 行、block.ts 1097 行）；utils 中伪 composable 命名混淆；litellm/duckdb 版本锁定；frappe-ui 为 vendored 副本需同步策略。
- 12 个 DocType，核心是 Builder Page。
