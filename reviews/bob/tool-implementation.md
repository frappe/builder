## Implemented behavior

- **Permission-aware reads:** get_document and run_python share `readable_doc`: fresh get_doc, document read permission check, field-level filtering, then serialization/projection/truncation. Single get_value/get_single_value use the same filtered reader. Explicitly requested fields and child rows cannot bypass the filtering.
- **Canonical replay:** WorkingTree resets `accepted_operations` for each apply. Batches yield ordered, detached update_block operations for accepted patches only. Style names/values, element tags, binding aliases/prefixes, and HTML-over-text precedence are canonicalized. Wholly rejected batches return FAILED with no replay operations; partial batches preserve accepted changes and explain rejections. Forbidden element updates and page-root removal are rejected. Add/move operations carry resolved positions; additions carry server-generated block_json. Inline repeat.items in add_block is explicitly rejected rather than silently discarded.
- **Unsets:** null styles delete the normalized key in base/mobile/tablet styles. Attribute changes clear both legacy/generated stores before assigning the canonical store, so set/unset cannot reveal stale id/ARIA/href values. Null binding values remove the binding.
- **Repeater compilation:** block wiring and static collection use the same normalized root and key. Python literals preserve booleans/nulls, quotes, Unicode and multiline strings; dotted keys use dictionary access. Invalid/private/template-literal keys, duplicate/overlapping static definitions, invalid items and missing templates are rejected. Nested static lists attach to each parent record, not an unrelated page-level key. Nested data supplied in parent items also works. Compressed repeaters with templates in c reconstruct as repeaters.
- **Existing data scripts:** persist_page rejects a differing generated shim before any draft write if a nonempty page_data_script already exists. Identical shims are permitted; generation without inline items leaves page_data_script untouched. There is no implicit concatenation or overwrite of arbitrary existing Python.
- **Icons:** compression retains ref, attributes, classes, responsive styles (including deeply nested tablet styles), and ordinary metadata. Expansion honors ref. Attribute classification is consistent. Explicit missing icon defaults are represented as nulls so expansion does not reintroduce an unset width/display/etc.
- **Forms:** exact input_name survives reserved DocType field renaming and confirmation normalization. Duplicate mappings are rejected. Required flags reach DocType and Web Form fields. Single Check checkboxes store 1/0; ordinary checkbox/radio controls contribute only checked values. Explicit multiple mappings store all successful values as JSON arrays in Text fields. Disabled controls/options/optgroups are excluded; hidden fields and external form-associated controls are included. Real forms use native submit events and validity checks; unrelated buttons do not bypass validation. Files and missing/ambiguous multiple mappings fail visibly. Generated handlers provide live status, preserve inputs on failure, allow retry, avoid duplicate initialization, and send an available CSRF token.
- **Form resources:** script identity includes page, endpoint and selector; another page's handler is not overwritten. Existing-connection lookup is selector-specific. Missing/unauthorized pages fail before provisioning. Reused schema/endpoint identity, required fields, publication/login/key/multiple settings are checked before DDL. Unsupported field types are rejected; Select intentionally maps to Data to store HTML option values.
